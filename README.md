# Exportar Chats Claude

Guarda en un ZIP tus conversaciones, proyectos y skills de **claude.ai**, con sus imágenes y archivos.
Para subirlos de nuevo a Claude usa [Importar Chats a Claude](https://github.com/alcalos9/extension_chrome_importar_claude).

## Instalar (1 minuto)
1. Aquí en GitHub: **Code → Download ZIP**, y descomprime el archivo en una carpeta que no vayas a borrar.
2. En Chrome abre `chrome://extensions` y activa **Modo de desarrollador** (arriba a la derecha).
3. Pulsa **Cargar descomprimida** y elige esa carpeta.
4. Abre claude.ai, inicia sesión y pulsa el icono de la extensión: se abre un panel a la derecha.

## Usar
Elige una pestaña del panel:
- **Conversación:** abre el chat en claude.ai → *Capturar conversación* → *Exportar ZIP*.
- **Proyectos** o **Skills:** marca los que quieras → *Exportar*.

## Bueno saber
- **Privado:** todo ocurre en tu computador; no se envía nada a nadie.
- **Si deja de funcionar:** claude.ai puede haber cambiado. Cuéntalo en la pestaña *Issues* de este repositorio.
- Proyecto independiente, sin relación con Anthropic ni OpenAI. Úsalo solo con tus propios datos.
